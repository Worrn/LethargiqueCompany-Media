# LethargiqueCompany media

Icons, banners and presentation images for the Lethal Company mods published by the **LethargiqueCompany** team on Thunderstore. This repository only holds images: no code, no game files and no third-party assets.

| Folder | Content |
|---|---|
| `brand/` | Lethargique Company logo |
| `modpack/` | Lethargique Company modpack icon |
| `fixes/` | Lethargique Company Fixes icon |
| `compat/` | Lethargique Company Compat icon |
| `menu/` | Lethargique Company Menu icon |
| `creatures/` | Lethargique Creatures icon, banner and family headers |

**Linking an image** (Thunderstore README, for example):
`https://raw.githubusercontent.com/Worrn/LethargiqueCompany-Media/main/creatures/banner.png`

File names are kept stable once published; a new design gets a new file name instead of replacing the old one.
